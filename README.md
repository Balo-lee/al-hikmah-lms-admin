# Al-Hikmah LMS — Admin Portal

Admin portal frontend for a full-stack Learning Management System, built during hands-on training with Al-Hikmah Technologies Services Limited. Manages courses, modules, quizzes, assignments, student submissions, and instructor accounts across a 13-page dashboard.

🔗 **Live demo:** https://balo-lee.github.io/al-hikmah-lms-admin

## Pages
Dashboard · Courses · Categories · Modules · Materials · Assignments · Quizzes · Questions · Submissions · Results · Students · Instructors · Profile

## Built with
HTML5 · CSS3 · JavaScript

## Team
Built collaboratively as a group project during training at Al-Hikmah Technologies; contributed the complete admin portal frontend.
